Executive Overview

🤖 Overview of the 5 Autonomous Core Systems

This technical document details the end-to-end execution flows, routes, schemas, and AI models powering the 5 specialized autonomous agents in the NoteNova ecosystem.

1. AI Revenue Recovery Agent

Autonomous 5-signal financial engine. Captures failed checkouts & OTP timeouts, runs Groq Llama-3.3 diagnosis, evaluates policy gates (≤ ₹5,000 auto vs > ₹5,000 HITL), mints 24h vouchers, and recovers revenue via WhatsApp & in-app alerts.

/api/agent/revenue-recovery/*
2. Instagram Growth Agent

1-Click direct Meta Graph API publisher for 8K Reels. Auto-schedules daily morning drafts at 06:00 AM IST, polls video containers until FINISHED status, publishes live, and purges Cloudinary storage automatically.

/api/instagram-agent/*
3. AI Client Acquisition Agent

B2B client project pipeline. Ingests leads, analyzes technical requirements with AI, drafts milestone proposals, dispatches WhatsApp/Email outreach, generates public escrow payment links (/pay/:code), and builds codebases.

/api/client-agent/*
4. Pochi (Admin Voice Assistant)

3D glowing Siri/Orb executive hologram. Speech-to-Text & Speech-to-Text interaction equipped with direct database mutation tools to modify batch prices, review refunds, and inspect live revenue analytics.

/api/admin/pochi/*
5. AI Academic Chatbot & Study Copilot

Omniscient student doubt solver built with local Xenova/all-MiniLM-L6-v2 vector embeddings (RAG). Intercepts PDF summarization (__PDF_SUMMARISE__), detects in-chat Promise-to-Pay commitments, diagnoses live payment declines, and provides real-time course recommendations from live MongoDB catalog.

/api/chatbot

🛠️ Technology & Model Stack

Primary Cognitive LLM: Groq Cloud SDK (llama-3.3-70b-versatile, qwen3.8-27b)
Fallback LLM: OpenRouter API (nvidia/nemotron-nano-9b-v2:free)
Payment Gateway: Razorpay Node SDK (HMAC-SHA256 Signed Webhooks)
Vector Embeddings: @xenova/transformers (all-MiniLM-L6-v2)
Voice Engine: Web Speech API (webkitSpeechRecognition + SpeechSynthesis)
Social Engine: Meta Graph API v21.0 (Instagram Business Container API)

💡 Key Features of the Chatbot & Pochi

🤝 Promise-to-Pay in Chat: If a student says "main kal pay karunga", the chatbot registers the commitment in FailedPayment, pauses recovery alerts, and confirms their seat.
📄 PDF Summarization: Parses uploaded notes using pdf-parse (up to 15,000 characters) and generates structured takeaways.
🛡️ Pochi Database Tools: Direct mutation of MongoDB records (Batch.price, RefundRequest, doubt responses) via voice.
🌐 Omniscient Catalog Injection: Chatbot checks real-time prices and never recommends courses the student already owns.
